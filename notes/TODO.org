** The switch-VT method is very restrictive
- This is good, if only SEB is allowed to be used.
- If usage of some other software is required, it is not obvious how
  the switch-VT method is to be used.
  - Maybe including a *preconfigured desktop environment* on the new VT
    could be more flexible.
    - Might also include *signed versions* of the allowed apps.
      - Or a fixed version with *known checksum*.
  - Using a *container*, it might be easier to control access to some
    resources (USB drive, network proxy)
    - However, the apps running in the container add to the memory
      used by the base system. Memory starved systems may fail (or
      start swapping).
  - On the other end of the spectrum: *netboot* to a linux environment.
    - (Something like this may already exist)
    - Instructions for BYOD may become longish.
